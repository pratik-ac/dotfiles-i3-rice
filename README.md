This repo contains my complete i3wm setup along with rice configurations for:

- i3 window manager
- Polybar
- Rofi
- Dunst notifications
- Picom compositor
- Alacritty terminal
- Flameshot, autorandr, neofetch, GTK settings, and wallpapers

Configured for a clean and minimalistic workflow.
